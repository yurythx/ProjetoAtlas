# Plano de Melhorias de Segurança e UX para Gestão de Usuários

Considerando o contexto atual de RBAC e multi-tenancy, aqui estão as melhorias recomendadas seguindo as melhores práticas de segurança e usabilidade:

## 1. Auditoria e Logs de Segurança (Backend)
Implementar logs detalhados para ações críticas de usuários.
- **Rastreabilidade**: Registrar quem criou/editou/removeu usuários e quando.
- **Monitoramento de Acesso**: Logar tentativas de login falhas e trocas de senha.
- **Implementação**: Estender o `AuditLog` já existente para cobrir todas as ações do `UserViewSet` e `InvitationViewSet`.

## 2. Bloqueio de Acesso e Proteção (Backend)
Melhorar a segurança ativa das contas.
- **Soft Delete (Desativação)**: Em vez de deletar usuários permanentemente, adicionar um campo `is_active` ou `archived_at` para desativar o acesso sem perder histórico.
- **Bloqueio de Conta**: Impedir login de usuários desativados (`is_active=False`) no JWT.

## 3. Melhorias na Interface de Gestão (Frontend)
Refinar a UX para administradores.
- **Confirmação de Ação Crítica**: Modal de confirmação com "digite o nome do usuário para confirmar" ao deletar/desativar.
- **Filtros Avançados**: Filtrar usuários por papel e status (ativo/inativo) na listagem.
- **Feedback Visual**: Badges de status (Ativo/Inativo) na lista de usuários.

## 4. Validações de Integridade (Backend)
Garantir consistência dos dados.
- **Proteção do Próprio Usuário**: Impedir que um admin exclua ou desative a si mesmo.
- **Proteção de Superusuário**: Impedir que admins comuns editem ou excluam superusuários.
